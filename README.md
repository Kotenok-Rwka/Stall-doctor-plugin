# Stall Doctor

Плагин для exteraGram: находит причину зависаний и сбоев Telegram и называет плагин-виновник.

- следит за интерфейсом, очередями и связью с сервером;
- при ошибке другого плагина показывает окно: что случилось и что можно сделать;
- разбирает журнал: краши, исключения Python, ANR, падения прошлых запусков;
- по каждой найденной проблеме простыми словами пишет, что случилось, что это значит и что делать;
- собирает полный отчёт для баг-репорта: его можно скопировать или отправить в Избранное.

**Приватность.** Сообщения, номера и адреса прокси в отчёт не попадают. Наружу ничего не отправляется.

**Безопасность.** Рискованные действия (перезагрузка плагинов, деление списка пополам) работают только по вашей кнопке и включаются отдельной настройкой.

Требования: exteraGram ≥ 12.10.6, SDK плагинов ≥ 1.4.5.0.

## Установка

Через каталог плагинов (exteraGram 13.1.1+): откройте

`https://t.me/exteraPluginRepo?git=https%3A%2F%2Fgithub.com%2FKotenok-Rwka%2FStall-doctor-plugin`

В настройках плагинов должен быть включён **Unknown sources**: плагины из Git считаются неизвестными источниками.

Анализатор при установке покажет предупреждения (запросы, хуки на методы приложения, обращение к `PluginsController` и `ExteraConfig`). Это ожидаемо: плагин-диагност вмешивается в систему по своей задаче, ничего скрытого в нём нет.

Вручную: скачайте `plugins/stall_doctor.py` и установите как `.plugin`.

## Структура репозитория

```
plugins/stall_doctor.py        сам плагин (имя файла = __id__)
extera-plugins.json            индекс каталога (собирается скриптом)
tools/build_index.py           сборка и проверка индекса
tests/                         тесты на заглушках SDK, телефон не нужен
.github/workflows/index.yml    тесты и автосборка индекса при пуше в main
CHANGELOG.md
```

## Разработка

```
pip install -r requirements-dev.txt
python -m pytest -q                 # тесты
python tools/build_index.py         # пересобрать extera-plugins.json
python tools/build_index.py --check # проверить, что индекс актуален
```

Выпуск новой версии: поменять `__version__` в `plugins/stall_doctor.py`, запустить тесты, закоммитить и сделать `git push` в `main`. Workflow сам пересоберёт индекс. Если индекс собран вручную, он должен лежать в том же коммите, иначе тест `test_committed_index_is_current` упадёт.

Тесты проверяют логику плагина на заглушках SDK и не заменяют проверку на устройстве. Загрузку папки `.github` через веб-интерфейс GitHub он может пропустить, надёжнее `git push`.
